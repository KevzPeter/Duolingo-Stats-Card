These league badges are Duolingo artwork, retrieved from the Duolingo web app's
`images/leagues/` CDN assets. Duolingo retains its rights to the artwork.
The app currently exposes verified badges for the ten leagues included here;
Amber, Aqua, Jade, Indigo, and Platinum use custom artwork in
`components/CustomLeagueBadge.tsx`; unknown league names use the generic icon.
